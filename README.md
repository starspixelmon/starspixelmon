# Stars Pixelmon

Site oficial do **Stars Pixelmon**, servidor brasileiro de Minecraft Java com o mod Pixelmon.

O grande diferencial do servidor são os **Starians**: espécies originais criadas pelo próprio Stars, que só existem aqui.

**IP do servidor:** `starspixelmon.com.br` · **Site:** [starspixelmon.com.br](https://starspixelmon.com.br) · **Discord:** [discord.gg/8XNCDBH5BE](https://discord.gg/8XNCDBH5BE)

## O que tem no site

- **Starian Dex**: os Starians do servidor, com arte, sprites e uma página para cada um.
- **Loja**: destaques da temporada, chaves das caixas, Star Coins e Star Tokens. Toda compra é feita na loja oficial e chega no jogo pelo Correio.
- **VIPs**: os planos Lunar, Solar, Astral, Cosmo e Estelar, com os kits de cada um.
- **Eventos**: o torneio em destaque, com prêmios e regras.
- **Comunidade**: redes sociais e o Discord.
- **Como jogar**: o passo a passo para entrar, o guia do mapa, a Área Estelar e os sistemas do servidor.

## Sobre os nomes

As criaturas originais do servidor se chamam **Starians**. As criaturas do mod são chamadas de **Pixelmon**.
